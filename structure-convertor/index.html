支持 .mcstructure / .litematic / .schem / .wsmr / .bdx / .nbt / .schematic / .mcworld / .mcpack / .mcaddon / .zip / .mca 文件。所有处理均在浏览器本地完成，文件不会上传到任何服务器。
说明：mcworld 输出为基岩版世界存档 zip，可直接放进存档目录打开；输出文件名为 名称@[x1,y1,z1]~[x2,y2,z2].mcworld，导入后结构即落在这些坐标上。mcstructure 输出体积较大，大结构建议优先转换为 wsmr 或 litematic。多区域文件转为其他格式时仅取第 1 个区域。世界文件可将文件名改为 名称@[x1,y1,z1]~[x2,y2,z2].mcworld，只转换该坐标范围（含端点）；输出文件名取 @ 前的名称。转为 BDX 时不保留原点信息。命令方块、告示牌等信息在 mcstructure ↔ BDX 转换中保留，箱子内的物品暂不保留。旧版 .schematic 为 Java 1.12 时代格式，部分新方块（1.13+ 才有的）导出后会变成空气，命令方块/告示牌信息不保留。
