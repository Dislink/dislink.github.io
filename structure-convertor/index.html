上传后自动识别格式（BD@ 头 / gzip / NBT 嗅探）。支持 .mcstructure / .litematic / .schem / .wsmr / .bdx / .nbt（Java 结构方块），以及世界类容器 .mcworld / .mcpack / .mcaddon / .zip（Java 版取 region/*.mca，基岩版取 db/ LevelDB）和单独的 .mca 区域文件（旧版 .schematic 暂不支持）。所有处理均在浏览器本地完成，文件不会上传到任何服务器。
说明：mcstructure 输出为未压缩 NBT，大结构体积会显著膨胀甚至超出内存；多区域文件（litematic 多 Region）转为 mcstructure / schem / bdx 时仅取第 1 个区域，转 wsmr / litematic 可完整保留。建议大结构优先转换为 wsmr 或 litematic。世界类容器（.mcworld / .zip 等）与 .mca 仅作为解析输入：整张世界会按所有区块的包围盒展开，体积可能远超单个结构，转换前请确认范围。
世界容器命名约定：名称@[x1,y1,z1]~[x2,y2,z2].mcworld —— 文件名带 @坐标范围 时只转换该世界坐标包围盒（含端点），输出文件名取 @ 前的名称；如 zhucheng@[-280,-64,-250]~[250,200,250].mcworld 只导出 [-280,-64,-250] 到 [250,200,250] 的区域。BDX 为基岩版命令流格式（BD@ 头 + Brotli），不存储原点与实体，原点信息会丢弃（重解析基点为 0,0,0）。
