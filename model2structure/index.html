上传模型
点击或拖入模型文件(.obj / .glb / .gltf / .fbx / .stl / .zip):OBJ 可连同 .mtl 与贴图一起拖入,FBX 可连同贴图一起拖入,整包 .zip 直接拖入即可
支持 OBJ(可带 .mtl 与 PNG/JPG 贴图)、GLB / glTF(不支持 DRACO / KTX2 / Meshopt 压缩与 .gltf 外链资源)、FBX(二进制 / ASCII,贴图按文件名自动关联)与 STL(二进制 / ASCII,无贴图按单色);也可直接上传 .zip 压缩包(.mtl 与贴图按包内路径自动关联,包内有多个模型时可选择其中一个)。模型按「最长边 = 分辨率」切成方块格,表面逐格采样贴图配色。
