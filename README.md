# dislink.github.io
工具站首页（index.html）按功能分类展示全部工具，支持按名称/标签搜索。当前上线工具：
> [midi2mcfunction：Midi音乐转换为播放音乐的mcpack行为包](midi2mcfunction/)  
> [midiconvertor：Midi音乐转换为 BDX / mcstructure / mcpack](midiconvertor/)  
> [img2mcfunction：各种图片转换为放置方块的mcpack行为包](img2mcfunction/)  
> [text2mcfunction：文字转换为粒子画mcpack行为包](text2mcfunction/)  
> [braille：图片/视频转盲文字符画（mcstructure / BDX / mcfunction）](braille/)  
> [img2block：图片/视频转地图画（mcstructure / BDX / mcfunction）](img2block/)  
> [video-character-art：视频转彩色字符画（mcstructure / BDX / mcfunction）](video-character-art/)  
> [mcfunctionconvertor：mcfunction 转 BDX / mcstructure](mcfunctionconvertor/)  
> [progressbar：计分板进度条 titleraw 命令生成](progressbar/)  
> [neteaseRegex：网易违禁词检测](neteaseRegex/)  
> [rawJSONEditor / rawJSONVisualEditor：原始 JSON 文本编辑器](rawJSONEditor/)  
> [netease-world-crypto：网易基岩版世界存档 db 加解密（支持文件夹/zip/mcworld，导出 zip 或 mcworld）](netease-world-crypto/)  
> [nbteditor：NBT 可视化编辑器](nbteditor/)  
> [structure-viewer：结构 3D 查看器（WASM）](structure-viewer/)  
> [structure-convertor：结构格式转换器（WASM）](structure-convertor/)
