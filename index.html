    音乐转换

    MIDI 转压缩指令

    将 MIDI 文件转换为基岩版压缩指令音乐 mcfunction 包，计分板分时调度大幅精简命令量，支持音色映射、多音轨合并、LRC 歌词，也可导出 BDX / mcstructure / mcworld 命令方块链
    BE mcpack MIDI 压缩指令

    MIDI 转换器

    MIDI 转 BDX / mcstructure / mcworld / mcfunction，支持命令方块结构生成与多文件 mcpack
    BDX mcstructure mcworld MIDI

    图片 / 视频创作

    图片转 mcfunction

    将任意图片转换为 setblock 命令阵列，支持 BE / JE 双版本
    BE / JE mcpack 图片

    文本转粒子 mcfunction

    将文本渲染为粒子效果 mcfunction，支持自定义字体
    BE mcpack 文本 粒子

    盲文字符画生成器

    图片/视频转 Braille 盲文字符画，支持抖动、阈值调节、反色，可导出 mcstructure / BDX / mcworld
    BE mcstructure 盲文

    地图画生成器

    图片转 Minecraft 方块结构（地图画），10 种抖动算法、Y 轴自适应居中，可导出 mcstructure / litematic / schem / BDX / mcfunction / mcworld 等
    BE 结构文件 地图画

    彩色视频字符画生成器

    视频转 Minecraft 彩色字符画，使用 § 颜色代码 + 字符映射，支持抖动开关、帧预览，可导出 mcstructure / BDX / mcworld
    BE actionbar 视频

    MC 调色盘像素画

    图片转 Minecraft 方块调色盘像素画，633 种方块色 + 183 地图色，10 种抖动算法，WASM 加速，可导出 PNG / 材料清单 / mcfunction / mcstructure / BDX / litematic / schem / mcworld 等
    像素画 调色盘

    结构与格式转换

    结构 3D 查看器

    在线查看 mcstructure / litematic / schem / BDX / nbt / mca / 旧版 schematic 结构与 mcworld 世界存档（Java 版 + 基岩版），支持分层、漫游、LOD 与贴图
    3D 查看器 结构

    结构格式转换器

    mcstructure / litematic / schem / wsmr / BDX / 旧版 schematic（MCEdit）互转，也支持 nbt / mca 与 mcworld 世界存档（Java 版 + 基岩版），支持大结构与多区域文件
    格式转换 结构

    结构命令提取/替换/转换器

    提取结构内命令方块的命令为 txt，支持字符串/正则批量替换与旧版 execute 转新语法，写回结构重新下载（mcstructure / BDX 等）
    命令方块 批量替换

    结构预览图

    拖入结构文件生成渲染预览图（等距俯视 + 正俯视），schem / schematic / litematic / mcworld 逐层流式解析超大结构也能出图，支持 mcstructure / BDX 等全格式与自定义相机、光源调节，下载 PNG
    预览图 超大结构
